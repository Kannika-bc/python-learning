# AI Quiz Game 🎯

An AI-powered multiple-choice quiz application built using Python and the Groq API.

## Features
- Generates 5 Python programming questions using AI.
- Provides 4 options for each question.
- Checks user answers.
- Calculates the final score.
- Handles API and JSON errors.

## Technologies Used
- Python
- Groq API
- JSON

## Setup

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

2. Set your Groq API key in PowerShell:

   ```powershell
   $env:GROQ_API_KEY="your_api_key"
   ```

3. Run the application:

   ```bash
   python quiz.py
   ```
